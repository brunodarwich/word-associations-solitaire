# Tarefas

Cada item tem escopo S/M (até aproximadamente cinco arquivos). Comandos de verificação: npm test, npm run build e npm run test:e2e.

- [ ] 1. Base navegável. Aceite: título e layout responsivo; verificar build e navegador. Dependências: nenhuma.
- [ ] 2. Primeira fase completa. Aceite: abertura, associação e vitória; verificar solução no motor. Depende: 1.
- [ ] 3. Monte e orçamento. Aceite: ordem correta, custos e vitória na última jogada; verificar testes. Depende: 2.
- [ ] Checkpoint 1: uma partida vencível, testes e build aprovados.
- [ ] 4. Recuperação. Aceite: dicas, desfazer e reinício preservam integridade; verificar limites e restauração. Depende: 3.
- [ ] 5. Fases 1–10. Aceite: conteúdo e tutorial disponíveis; verificar dez soluções. Depende: 4.
- [ ] 6. Fases 11–20. Aceite: conteúdo e dificuldade crescente; verificar dez soluções. Depende: 5.
- [ ] Checkpoint 2: vinte fases verificadas e revisão editorial.
- [ ] 7. Fases 21–30. Aceite: conteúdo avançado revisado; verificar dez soluções. Depende: 6.
- [ ] 8. Campanha persistente. Aceite: desbloqueio, estrelas e retomada; verificar recarga e dados inválidos. Depende: 7.
- [ ] 9. Interação acessível. Aceite: toque, arraste e teclado equivalentes; verificar 360 px, foco e acessibilidade. Depende: 8.
- [ ] Checkpoint 3: trinta fases, testes e build aprovados.
- [ ] 10. Publicação. Aceite: GitHub e Pages ativos; verificar URL, recarga e recursos. Depende: 9.
